# Phase quick Plan 260616-e76: Fix Empty Progress Ring Visibility on Light Theme Summary

**One-liner:** Brightness-aware `backgroundColor` for `CircularPercentIndicator` — full-opacity `surfaceContainerHighest` on light theme, 30%-opacity on dark theme.

## What Was Built

A single local variable `ringTrackColor` was added to `_buildContent` in `HomeScreen`, immediately after the existing `goalMetColor` variable. The variable selects between:

- **Light theme:** `colorScheme.surfaceContainerHighest` (full opacity) — produces a visible medium-grey ring track against the white scaffold background
- **Dark theme:** `colorScheme.surfaceContainerHighest.withValues(alpha: 0.3)` — unchanged from the previous behaviour, maintaining the subtle ghost-track appearance

The `CircularPercentIndicator`'s `backgroundColor` parameter was updated to use `ringTrackColor` instead of the hardcoded 30%-opacity expression.

No new imports, dependencies, or hardcoded colour values were introduced.
