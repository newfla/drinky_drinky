## v1.3 Requirements

Requirements for milestone v1.3 (Multilingual Support). All 9 requirements shipped and validated by UAT on 2026-06-15.

### Infrastruttura l10n

- [x] **L10N-01**: App carica le traduzioni via Flutter gen-l10n (`flutter_localizations` SDK dep, `l10n.yaml` con `synthetic-package: false`, `generate: true` in `pubspec.yaml`)
  - **Outcome**: Validated — `l10n.yaml` with `synthetic-package: false`, `output-dir: lib/l10n/generated/` wired in `pubspec.yaml`. `flutter gen-l10n` produces `app_localizations.dart` without errors.

- [x] **L10N-02**: `MaterialApp.router` dichiara `localizationsDelegates` e `supportedLocales` per it/en/fr/es; lingua di sistema seguita automaticamente con EN fallback via `basicLocaleListResolution`
  - **Outcome**: Validated with intentional deviation — uses custom `localeListResolutionCallback` that resolves `locales.first` only, matching primary-only strategy confirmed in Phase 13 UAT. Observable behavior (device language followed, English fallback) identical.

- [x] **L10N-03**: `initializeDateFormatting()` chiamata in `main()` per le 4 lingue (table_calendar usa intl per i nomi dei mesi)
  - **Outcome**: Validated — called before `runApp()` for en/it/fr/es. TableCalendar displays month/day names in device language.

### Estrazione stringhe UI

- [x] **L10N-04**: `HydrationCalculatorScreen` refactora `_sexFactors` e `_climateLabels` da Italian display-string keys a enum (`BiologicalSex` / `ClimateLevel`) — prerequisito anti-crash per tutte le lingue non-italiane
  - **Outcome**: Validated — `hydration_enums.dart` introduces `BiologicalSex` and `ClimateLevel` enums. Calculator works in all 4 locales without crash.

- [x] **L10N-05**: Tutte le stringhe visibili nelle 6 schermate (home, settings, history/calendar, calculator, permission screen, add-intake bottom sheet) estratte in `app_en.arb` come template canonico con chiavi semantiche e metadata `@key`
  - **Outcome**: Validated — 79-key `app_en.arb` with full `@key` metadata. All 6 screens use `context.l10n`. Zero hardcoded user-visible strings confirmed by UAT.

- [x] **L10N-06**: File `app_it.arb`, `app_fr.arb`, `app_es.arb` prodotti con traduzioni machine-generated; plurali ICU corretti (French: `one` category copre 0 e 1)
  - **Outcome**: Validated — 79 keys per locale with ICU plural forms. 3 inline corrections applied during Phase 13 UAT (ring text centering, Italian/Spanish todaysIntake strings).

### Notifiche

- [x] **L10N-07**: `NotificationService` usa `lookupAppLocalizations(basicLocaleListResolution(platformDispatcher.locales, supportedLocales))` per ottenere titolo/corpo del reminder nella lingua corrente senza `BuildContext`
  - **Outcome**: Validated with intentional deviation — uses custom `_resolveLocale()` (primary-only, D-01 LOCKED per 14-CONTEXT.md) rather than `basicLocaleListResolution`. Observable outcome identical. Notification body confirmed in IT/FR/ES by Phase 14 UAT.

### Platform Config

- [x] **L10N-08**: iOS `Info.plist` aggiunge `CFBundleLocalizations` con `it`, `fr`, `es` (senza questa voce iOS non segnala il locale a Flutter anche se il device è impostato in italiano)
  - **Outcome**: Validated — `CFBundleLocalizations` array with `en`, `it`, `fr`, `es` in `ios/Runner/Info.plist` (lines 9-15). Includes `en` explicitly (superset of requirement, harmless). iOS locale propagation confirmed by Phase 14 UAT.

- [x] **L10N-09**: Android `build.gradle.kts` aggiunge `resConfigs("en", "it", "fr", "es")` per bundle splits corretti
  - **Outcome**: Validated — `resourceConfigurations += setOf("en", "it", "fr", "es")` in `defaultConfig {}` block (line 31).

## Out of Scope

| Feature | Reason |
|---------|--------|
| Override lingua in-app | Sistema deve seguire il device; override manuale aggiunge complessità UX non giustificata per v1.3 |
| Layout RTL | en/it/fr/es sono tutte LTR; nessun rischio |
| App Store metadata localization | Testi store (description, screenshots) gestiti fuori dal codebase |
| Notification channel name localization | Canal name raramente visibile all'utente; polish item per v1.4+ |
| Salvataggio lingua scelta | Privacy by design — nessun dato personale aggiuntivo; locale viene da sistema |
