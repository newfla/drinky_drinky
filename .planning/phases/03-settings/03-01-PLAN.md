## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> Repository | Numeric text field input (preset amounts) crosses into DB write path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | Preset edit TextField | mitigate | Client-side validation (50-2000 range check, int parse) disables Confirm button. Repository-level ArgumentError guard (amountMl > 0) provides defense-in-depth. Drift uses parameterized queries -- no SQL injection risk |
| T-03-02 | Tampering | Slider values | accept | Slider min/max/divisions inherently constrain values. int conversion via .toInt() on snapped values is lossless. Repository validates dailyTargetMl > 0 and notificationIntervalMinutes > 0 |
| T-03-03 | Tampering | DND hour/minute values | accept | showTimePicker returns valid TimeOfDay (hour 0-23, minute 0-59). Repository validates hour/minute ranges with ArgumentError |
</threat_model>
