Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding between icon and label |
| sm | 8px | Compact element spacing, gap between quick-add buttons |
| md | 16px | Default element spacing, screen horizontal padding |
| lg | 24px | Section padding, gap between progress ring and quick-add row |
| xl | 32px | Gap between quick-add row and timeline section |
| 2xl | 48px | Top padding above progress ring |
| 3xl | 64px | Not used in Phase 2 |

Exceptions: Bottom navigation bar uses M3 default height (80px). Touch targets for quick-add buttons use minimum 48px height per M3 accessibility guidelines.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `Theme.colorScheme.surface` | Scaffold background, screen area |
| Secondary (30%) | `Theme.colorScheme.surfaceContainerLow` | Timeline list item background, card containers |
| Accent (10%) | `Theme.colorScheme.primary` (M3 blue from `colorSchemeSeed: Colors.blue`) | Progress ring fill (< 100%), quick-add FilledButton backgrounds, bottom nav selected icon |
| Success | `Colors.green` (M3 green, shade 600) | Progress ring fill at 100% goal completion |
| Destructive | not used in Phase 2 | N/A |

Accent reserved for:
1. Progress ring arc fill (when below 100%)
2. Quick-add FilledButton backgrounds
3. Bottom navigation bar selected icon/label
4. SnackBar "UNDO" action text

Success green reserved for:
1. Progress ring arc fill at exactly 100% or above

The progress ring track (unfilled portion) uses `Theme.colorScheme.surfaceContainerHighest` at 30% opacity.

### Home Screen Layout (top to bottom)

1. **AppBar**: Title "Drinky Drinky", no actions in Phase 2
2. **Progress Ring Section** (centered, 48px top padding)
   - Widget: `CircularPercentIndicator` from `percent_indicator` package
   - Diameter: 200px
   - Stroke width: 12px
   - Line cap: `StrokeCap.round`
   - Fill color: `colorScheme.primary` when < 100%, `Colors.green.shade600` when >= 100%
   - Background color: `colorScheme.surfaceContainerHighest` at 0.3 opacity
   - Animation: `animateFromLastPercent: true`, duration 600ms
   - Center child: Column with current/target text
     - Below 100%: "750 / 2000 ml" (Display 32px)
     - At 100%: "Goal reached!" (Display 32px, green color)
3. **Quick-Add Row** (24px below ring, 16px horizontal padding)
   - Layout: `Row` with `MainAxisAlignment.spaceEvenly`
   - Widget per button: `FilledButton`
   - Button label: "+{amount} ml" (e.g. "+200 ml", "+300 ml", "+400 ml", "+500 ml")
   - Button height: minimum 48px (M3 touch target)
   - Default presets from DB seed: 200, 300, 400, 500 ml
4. **Timeline Section** (32px below quick-add row)
   - Section header: "Today's Intake" (Body 16px, medium weight 500)
   - Widget: `ListView.builder` inside `Expanded`
   - Each row: `ListTile` or custom `Row`
     - Left: time "14:32" (Label 14px, `colorScheme.onSurfaceVariant`)
     - Right: "+200 ml" (Body 16px, `colorScheme.onSurface`)
   - Row background: `colorScheme.surfaceContainerLow`
   - Row separator: 1px `Divider` using `colorScheme.outlineVariant`
   - Sort order: newest first (most recent entry at top)

## Interaction Contracts

### Quick-Add Flow

1. User taps a FilledButton (e.g. "+200 ml")
2. `waterRepository.insertEntry(amountMl, DateTime.now(), todayDateKey())` is called
3. Riverpod streams (`totalMlForDate`, `waterEntriesForDate`) emit new values
4. Progress ring animates from previous percentage to new percentage (600ms)
5. Timeline prepends the new entry at the top
6. SnackBar appears: "+200 ml added [UNDO]"
7. If new total >= dailyTargetMl: ring color transitions from primary blue to green, center text changes to "Goal reached!"

### Undo Flow

1. User taps "UNDO" on SnackBar within 5 seconds
2. `waterRepository.deleteLastEntry(todayDateKey())` is called
3. Riverpod streams emit updated values
4. Progress ring animates back to previous percentage
5. Timeline removes the entry
6. SnackBar is dismissed
7. If total drops below dailyTargetMl: ring color reverts to primary blue, center text reverts to "{current} / {target} ml"

### Progress Ring States

| State | Ring Color | Center Text | Center Text Color |
|-------|-----------|-------------|-------------------|
| 0% (empty) | Primary blue (track only visible) | "0 / 2000 ml" | `colorScheme.onSurface` |
| 1-99% | Primary blue fill | "{current} / {target} ml" | `colorScheme.onSurface` |
| >= 100% | Green (shade 600) fill | "Goal reached!" | `Colors.green.shade600` |

### Loading States

| Data | Loading Widget | Placement |
|------|---------------|-----------|
| Settings + total | `CircularProgressIndicator` centered on screen | Replaces entire body |
| Timeline entries | Empty state (see Copywriting below) | Timeline section |

### Error States

Riverpod `AsyncValue.error` is handled with inline error display, not a full-screen error. The progress ring section shows the last known value (optimistic) while the timeline section shows the error message.

## Data Contracts

Providers consumed by this phase (all from Phase 1):

| Provider | Type | Used For |
|----------|------|----------|
| `waterEntriesForDateProvider(dateKey)` | `AsyncValue<List<WaterEntryEntity>>` | Timeline list |
| `totalMlForDateProvider(dateKey)` | `AsyncValue<int>` | Progress ring percentage calculation |
| `userSettingsProvider` | `AsyncValue<UserSettingsEntity>` | Daily target (denominator), read `dailyTargetMl` |
| `drinkPresetsProvider` | `AsyncValue<List<DrinkPresetEntity>>` | Quick-add button labels and amounts |
| `waterRepositoryProvider` | `WaterRepository` | `insertEntry()` and `deleteLastEntry()` calls |

Key computation: `percentage = (totalMl / dailyTargetMl).clamp(0.0, 1.0)`

## Router Changes Required

The current router uses flat `GoRoute` paths without a shell. Phase 2 requires converting to `StatefulShellRoute.indexedStack` to support the bottom `NavigationBar` with persistent tab state.

| Current | Phase 2 |
|---------|---------|
| `GoRoute('/')` -> `HomeScreen` | `StatefulShellRoute.indexedStack` with `NavigationBar` |
| `GoRoute('/history')` -> `HistoryScreen` | Branch 1: `/history` (History tab) |
| `GoRoute('/settings')` -> `SettingsScreen` | Branch 2: `/settings` (Settings tab) |
| No navigation shell | Branch 0: `/` (Home tab, initial) |
