## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `colorScheme.surface` | Scaffold background |
| Secondary (30%) | `colorScheme.surfaceContainerLow` | Card backgrounds (streak card) |
| Accent (10%) | `colorScheme.primary` (blue) | Selected day highlight, today indicator ring, month nav arrows |
| Goal Met | `Colors.green.shade600` | Calendar day background for days where intake >= daily target |
| Goal Missed | `Colors.red.shade600` | Calendar day background for past days where intake < daily target |
| Goal Met (muted) | `Colors.green.shade600.withValues(alpha: 0.15)` | Calendar day cell fill behind green days |
| Goal Missed (muted) | `Colors.red.shade600.withValues(alpha: 0.15)` | Calendar day cell fill behind red days |
| Neutral | No color / default | Future days and today-with-no-data: no special decoration |

### Color Application Rules

1. **Calendar day cells use muted fills with bold text colors.** Each decorated day cell gets a `BoxDecoration` with `shape: BoxShape.circle`, filled with the muted (alpha 0.15) color. The day number text uses the full `Colors.green.shade600` or `Colors.red.shade600`.
2. **Today gets an outlined ring** using `colorScheme.primary` with `BoxDecoration(border: Border.all(...), shape: BoxShape.circle)` and no fill -- so it does not conflict with green/red fills. If today also has data and the goal is met/missed, the green/red muted fill takes priority and the today ring overlays it.
3. **Future days have no decoration** -- default text color, no background.
4. **Days with zero entries have no decoration** -- they are neither green nor red (the user simply did not use the app that day; we do not penalize with red for days before the app was installed).
5. **`Colors.green.shade600` is the same green used on HomeScreen** for goal-met progress ring (consistency).

Accent reserved for: today indicator ring, selected day highlight, month navigation arrow icons, streak flame icon.

### CalendarBuilders Day Decoration Logic

For each visible day, the builder checks:

```
if (day.isAfter(today)) -> return null (default rendering, no decoration)
if (day == today && no entries) -> today ring only (primary color border)
if (dailyTotalForDay >= dailyTarget) -> green muted fill + green text
if (dailyTotalForDay > 0 && dailyTotalForDay < dailyTarget) -> red muted fill + red text
if (dailyTotalForDay == 0 && day.isBefore(today)) -> no decoration (not penalized)
```

Day cell decoration widget structure:
```dart
Container(
  margin: const EdgeInsets.all(4),
  decoration: BoxDecoration(
    shape: BoxShape.circle,
    color: fillColor,  // muted green, muted red, or null
    border: isToday ? Border.all(color: colorScheme.primary, width: 2) : null,
  ),
  alignment: Alignment.center,
  child: Text(
    '${day.day}',
    style: TextStyle(
      color: textColor,  // green.shade600, red.shade600, or default
      fontWeight: FontWeight.w500,
    ),
  ),
)
```

## State Management

| State | Type | Source |
|-------|------|--------|
| `_focusedDay` | `DateTime` | Local widget state, updated on page change |
| `_selectedDay` | `DateTime?` | Local widget state, updated on day tap |

| Daily target | `int` | From `userSettingsProvider` |
| Current streak | `int` | Computed from monthly totals, walking backwards from yesterday |

```dart
}
```

### Streak Calculation

Streak is computed client-side from the daily totals data:
1. Start from yesterday (today is incomplete, do not count it)
2. Walk backwards day by day
3. For each day, check if total >= daily target
4. Stop counting when a day does not meet the target or has zero entries
5. The count of consecutive qualifying days is the streak

## Accessibility

| Concern | Approach |
|---------|----------|
| Color-only meaning (green/red) | Day cells include semantic labels via `Semantics` widget: "June 3: goal met" or "June 3: goal not met" |
| Contrast ratio | `Colors.green.shade600` (#43A047) on white: 3.4:1 for large text (14px bold qualifies). `Colors.red.shade600` (#E53935) on white: 4.0:1. Both pass WCAG AA for large text. Muted fills (alpha 0.15) serve as background only. |
| Touch targets | Calendar day cells are 42px minimum (table_calendar default). Meets 44px recommendation when including cell margin. |
| Screen reader | Streak card reads as "7 day streak" naturally. Calendar navigation buttons have built-in labels from table_calendar. |
