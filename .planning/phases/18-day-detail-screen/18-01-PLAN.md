Create lib/presentation/screens/day_detail_screen.dart as a ConsumerWidget (not ConsumerStatefulWidget -- no local mutable state needed). Per D-06, D-07, D-08, D-09.

Constructor: receives required String dateKey parameter.

Imports: flutter/material.dart, flutter_riverpod, fl_chart/fl_chart.dart, intl (DateFormat), dart:math (max function), stream_providers.dart, target_history_entry.dart, water_entry_entity.dart, l10n_extensions.dart.

Duplicate _toDateKey and _findActiveTarget as file-private helpers at the top (same strategy as monthly_bar_chart.dart and history_screen.dart).

Build method structure:
1. Watch two providers: ref.watch(waterEntriesForDateProvider(dateKey)) and ref.watch(allTargetHistoryProvider).
2. Parse the dateKey to DateTime via DateTime.parse(dateKey) for AppBar title formatting.
3. Compute locale via Localizations.localeOf(context).toString().
4. Format AppBar title via DateFormat.yMMMMd(locale).format(parsedDate) per D-06.
5. Return Scaffold with AppBar (title = formatted date).
6. Body: use nested AsyncValue.when pattern from history_screen.dart -- outer on entriesAsync, inner on targetsAsync. Loading shows CircularProgressIndicator. Error shows context.l10n.errorLoadingData.

When data is available:

EMPTY STATE (CHART-10): If entries list is empty, show a Card (margin: EdgeInsets.symmetric(horizontal: 16), padding: EdgeInsets.all(16)) with Center child Text using context.l10n.dayDetailNoEntries, styled with theme.textTheme.bodyLarge, color: colorScheme.onSurfaceVariant.

CHART + TOTAL (CHART-08, CHART-09):
1. Compute active target for this dateKey using _findActiveTarget(targets, dateKey).
2. Build total text using context.l10n.dayDetailTotal with (totalMl, targetMl) -- where totalMl = entries.fold(0, (sum, e) => sum + e.amountMl).
3. Group entries by minutes-since-midnight (entry.loggedAt.hour * 60 + entry.loggedAt.minute). Entries at the same minute get multiple barRods in the same BarChartGroupData per D-07. Sort groups by x (minutes-since-midnight) ascending.
4. Bar color: Theme.of(context).colorScheme.primary for all bars (not green/red -- these are individual additions, not goal-met indicators). Per Claude's Discretion in CONTEXT.
5. Bar width: 10 (wider than monthly chart's 6 since fewer bars).
6. borderRadius: BorderRadius.vertical(top: Radius.circular(2)) matching monthly chart pattern.
7. maxY: max(actualMaxMl * 1.1, 100.0) -- mandatory explicit ceiling per WR-02 pitfall. actualMaxMl = max of all entry amountMl values.
8. BarChart key: ValueKey('day-$dateKey') -- mandatory per WR-01 pitfall.
9. BarTouchData with handleBuiltInTouches: true. Tooltip shows the HH:mm time on line 1 and "{ml} ml" on line 2 (same tooltip pattern as monthly chart).
10. Bottom titles (x-axis): show HH:mm labels. Use entry's loggedAt to derive label. reservedSize: 30 (slightly more than monthly chart's 24 to accommodate HH:mm text). Only show labels for first entry in each group to avoid overlap.
11. Left titles (y-axis): show ml values. reservedSize: 40. Skip min and max values (same pattern as monthly chart). Format as integer ml values (no L conversion -- these are individual entries, typically 100-500 ml).
12. Hide top and right titles.
13. gridData: FlGridData(drawVerticalLine: false, drawHorizontalLine: true).
14. borderData: FlBorderData(show: false).
15. SizedBox height for BarChart: 220 (increased from monthly chart's 180 per Claude's Discretion, HH:mm labels need vertical space).

Layout: SingleChildScrollView wrapping a Column with crossAxisAlignment: CrossAxisAlignment.stretch. Children:
- SizedBox(height: 24) top padding
- Card containing Column with: total text (bodyLarge style), SizedBox(height: 12), SizedBox(height: 220) with BarChart. Card margin: EdgeInsets.symmetric(horizontal: 16), padding: EdgeInsets.all(16).
- SizedBox(height: 24) bottom padding
