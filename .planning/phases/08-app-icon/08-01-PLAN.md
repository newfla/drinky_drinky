  <action>
Create directory `tool/` and file `tool/generate_icon.dart` per D-01.

The script is a pure-Dart CLI program (no Flutter imports, no dart:ui). It uses `package:image/image.dart` with the `img` prefix alias.

Imports: `dart:io` and `package:image/image.dart as img`.

main() function (async, Future of void):
- Define constants: size = 1024, background RGB = (0x15, 0x65, 0xC0) which is #1565C0 per D-04.

- Create flat icon (per D-02 — `assets/icon/app_icon.png`):
  Construct `img.Image(width: size, height: size, numChannels: 4)`.
  Fill entire canvas with `img.ColorRgba8(0x15, 0x65, 0xC0, 255)` — solid opaque blue. This satisfies D-06 (iOS opaque — no transparent pixels exist).
  Call `_drawGlass(flat)` to render the white glass silhouette.

- Create foreground icon (per D-02 — `assets/icon/app_icon_foreground.png`):
  Construct `img.Image(width: size, height: size, numChannels: 4)`.
  Explicitly fill with `img.ColorRgba8(0, 0, 0, 0)` — fully transparent background (safety measure per RESEARCH.md Open Question 1).
  Call `_drawGlass(fg)` to render the white glass silhouette on transparent background.

- Create output directory: `Directory('assets/icon').createSync(recursive: true)` per D-03.
- Save flat icon: `await img.encodePngFile('assets/icon/app_icon.png', flat)`
- Save foreground: `await img.encodePngFile('assets/icon/app_icon_foreground.png', fg)`
- Print confirmation message.

_drawGlass() helper function (void, takes img.Image):
- Define white color: `img.ColorRgba8(255, 255, 255, 255)` per D-05.
- Draw a trapezoid glass body using `img.fillPolygon` with vertices that stay within the Android adaptive safe zone (center 66% = pixels [174, 850] on 1024 canvas). Claude has discretion over exact geometry per CONTEXT.md Claude's Discretion.
- The glass should be a recognizable water glass: wider at top, narrower at bottom (trapezoid). Consider adding a water fill line (a horizontal division where the lower portion could be drawn in a slightly different shade or the upper portion left as the glass rim area). The glass shape should be simple, flat design, no gradients, no shadows per D-05.
- All vertex coordinates must satisfy: 174 <= x <= 850 and 174 <= y <= 850.

After creating the file, run: `dart run tool/generate_icon.dart` from the repo root to generate both PNGs.
