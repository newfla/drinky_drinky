       a. Compute `daysInMonth` via `DateTime(year, month + 1, 0).day`.
       b. Compute `isCurrentMonth` by comparing year/month to `DateTime.now()`.
       c. Compute the last valid day: if isCurrentMonth then `DateTime.now().day`, else `daysInMonth`.
       d. Compute `endDateKey` as the dateKey for the last day of the month (for target line, per D-06). Use a local helper `_toDateKey` identical to the one in history_screen.dart.

Empty-state check (CHART-05, per D-05): if `monthTotals.isEmpty`, return a Card (per D-01 pattern: `Card(margin: EdgeInsets.symmetric(horizontal: 16), child: Padding(padding: EdgeInsets.all(16), child: ...))`) containing a centered Text with a hardcoded empty-state string "No data this month" (localization is Phase 18 scope). Style with `Theme.of(context).textTheme.bodyLarge` and `colorScheme.onSurfaceVariant`.

    6. Bar generation (CHART-01, CHART-02, per D-04, D-05): iterate days 1 through lastValidDay. For each day, look up `monthTotals[dateKey]`. Create a `BarChartGroupData` with `x: day` and one `BarChartRodData`:
       - `toY: total.toDouble()` (where total defaults to 0 if no entry).
       - Color logic per D-04: if `total >= targetMl && targetMl > 0` use green, else if `total > 0` use red, else skip the bar (toY remains 0, no visible bar per D-04 "total == 0 -> nessuna barra visibile").
       - Green: `brightness == Brightness.dark ? Colors.green.shade400 : Colors.green.shade600`.
       - Red: `brightness == Brightness.dark ? Colors.red.shade400 : Colors.red.shade600`.
       - `width: 6` (narrow enough for 31 bars on 360dp).
       - `borderRadius: BorderRadius.vertical(top: Radius.circular(2))`.

    7. Compute `maxY`: `max(actualMaxValue, targetMl.toDouble()) * 1.1` where actualMaxValue is the maximum toY across all bars. Floor of 100.0 if everything is zero (Pitfall 1).

    8. Target line (CHART-03, per D-06): `ExtraLinesData(horizontalLines: [HorizontalLine(y: targetMl.toDouble(), color: colorScheme.onSurfaceVariant.withValues(alpha: 0.5), strokeWidth: 1.5, dashArray: [8, 4])])`.

    9. Tooltips (CHART-04): `BarTouchData(handleBuiltInTouches: true, touchTooltipData: BarTouchTooltipData(getTooltipItem: callback))`. The `getTooltipItem` callback returns a `BarTooltipItem` with text "${rod.toY.toInt()} ml". Never use `showingTooltipIndicators` (Pitfall 3).

    10. Axis labels:
        - Bottom (x-axis): `SideTitles(showTitles: true, reservedSize: 24, getTitlesWidget: callback)`. The callback shows day number for days 1, 5, 10, 15, 20, 25, and the last day of month. Return `SideTitleWidget(meta: meta, child: Text('$day', style: TextStyle(fontSize: 10)))` for those days, `SizedBox.shrink()` for others.
        - Left (y-axis): `SideTitles(showTitles: true, reservedSize: 40)` (Pitfall 12). Let fl_chart auto-calculate interval.
        - Top and right: `SideTitles(showTitles: false)`.

    11. Grid: `FlGridData(drawVerticalLine: false, drawHorizontalLine: true)`.

    12. Border: `FlBorderData(show: false)`.

    13. Wrap BarChart in `SizedBox(height: 180)` per D-02. Apply `ValueKey('$year-$month')` on the BarChart widget (Pitfall 2). Set `BarChartAlignment.spaceEvenly`.

    14. Wrap the SizedBox in a Card per D-01: `Card(margin: EdgeInsets.symmetric(horizontal: 16), child: Padding(padding: EdgeInsets.all(16), child: SizedBox(...)))`.
